# PalindromeChecker App
 
## Overview
 
The **PalindromeChecker App** is a console-based Java application designed to explore different algorithms and data structures used to determine whether a string is a palindrome.
 
A palindrome is a word or phrase that reads the same forwards and backwards (e.g., *madam*, *racecar*).
 

## Project Goals
 
The application helps developers understand:
 
* String manipulation in Java
* Fundamental data structures
* Algorithm design
* Object-Oriented Programming principles
* Performance comparison between approaches
