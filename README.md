**UC6: Queue + Stack Based Palindrome Check**

---

**Goal**
 
Demonstrate FIFO and LIFO behavior using Queue and Stack.

---
 
**Flow**
 
- Insert characters into a queue.
 
- Push the same characters into a stack.
 
- Dequeue characters from the queue.
 
- Pop characters from the stack.
 
- Compare both outputs to verify palindrome.

---
 
**Data Structure**
 
Queue, Stack
